# URL Shortener — Java + Spring Boot + MySQL

A beginner-friendly URL shortener project. It creates short codes, stores the mapping in MySQL, and redirects requests to the original URL.

## Requirements

- JDK 17 or newer
- Maven 3.6.3+ (or use the Maven wrapper generated by your IDE)
- MySQL 8.x
- Postman or curl (optional)

## 1. Create the database

Run this in MySQL:

```sql
CREATE DATABASE url_shortener;
```

## 2. Configure database credentials

Set environment variables before starting the app, or edit `src/main/resources/application.properties`.

Windows PowerShell example:

```powershell
$env:DB_USERNAME="root"
$env:DB_PASSWORD="your_mysql_password"
```

Linux/macOS example:

```bash
export DB_USERNAME=root
export DB_PASSWORD='your_mysql_password'
```

The default username is `root`; the default password is blank. Change these for your local setup.

## 3. Run the app

From the project root:

```bash
mvn spring-boot:run
```

Or open the folder in IntelliJ IDEA / Eclipse as a Maven project and run `UrlShortenerApplication`.

## 4. Create a short URL

```bash
curl -i -X POST http://localhost:8080/api/urls \
  -H "Content-Type: application/json" \
  -d "{\"originalUrl\":\"https://example.com/products/123\"}"
```

Example response (the code will differ):

```json
{
  "shortCode": "aB12xY",
  "shortUrl": "http://localhost:8080/aB12xY",
  "originalUrl": "https://example.com/products/123"
}
```

## 5. Follow the redirect

Open `http://localhost:8080/aB12xY` in your browser, replacing the code with the one returned by the API.

To inspect the redirect without following it:

```bash
curl -i http://localhost:8080/aB12xY
```

Expected: `302 Found` and a `Location` header containing the original URL.

## API summary

- `POST /api/urls` — create a short URL. Body: `{"originalUrl":"https://example.com"}`
- `GET /{shortCode}` — redirect to the original URL.
- Unknown codes return `404 Not Found`.
- Invalid input returns `400 Bad Request`.

## Learning notes

- The unique database constraint is the final protection against duplicate codes.
- The service retries if a generated code collides.
- The redirect endpoint only redirects; it does not fetch the target page on the server.
- This is a learning baseline. Before production, add rate limiting, abuse prevention, monitoring, migrations (e.g. Flyway), and more robust URL/domain policies.
